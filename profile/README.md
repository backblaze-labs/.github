## Developer tools & SDKs

| Project | Description |
| --- | --- |
| [genblaze](https://github.com/backblaze-labs/genblaze) | Open-source Python SDK for orchestrating generative-AI media pipelines across video, audio, and image providers — with built-in provenance for every output. |
| [b2-sdk-typescript](https://github.com/backblaze-labs/b2-sdk-typescript) | Backblaze-maintained TypeScript / JavaScript SDK for B2 Cloud Storage. |
| [b2-mcp](https://github.com/backblaze-labs/b2-mcp) | The official Model Context Protocol server for B2 — a focused, safe 40-tool surface for any MCP-compatible AI client. |
